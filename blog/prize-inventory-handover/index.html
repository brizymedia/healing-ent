행사 경품 재고 관리: 입고·불출·미수령 인계표

읽는 시간 약 6분

행사 경품 재고 관리는 당첨 기록과 실제로 건넨 기록을 분리하는 것부터 시작합니다. 이름을 정확하게 호명해도 실물을 다른 상자에서 꺼내거나 수령 전인데 완료로 표시하면 정산이 꼬입니다.

시상 명단이 아니라 입고된 물품이 누구에게 어떤 상태로 넘어갔는지 확인하는 방법을 정리합니다.

이 글의 요점
  • 품목 코드를 포장과 관리표에 같이 붙입니다.
  • 당첨 확정, 전달 대기, 수령 완료를 나눠 기록합니다.
  • 남은 물품은 미수령분과 사용하지 않은 예비분을 구분해 인계합니다.

1. 행사 경품 재고 관리는 실물 확인이 출발점입니다

구매 목록이나 후원 약속은 실제 입고 목록과 다릅니다. 행사장에 도착한 상자를 확인하고, 목록에만 있는 물품은 입고 예정으로 남겨 둡니다.

겉포장이 같아도 내용물이 다를 수 있으므로 공급처가 제공한 표시와 품목명을 맞춥니다. 밀봉을 풀어도 되는지 불분명하면 임의로 개봉하지 말고 주최 측 담당에게 확인합니다.

확인 항목적을 내용다음 처리
품목 코드포장과 목록에 같은 식별 표시이름이 비슷한 물품 구분
입고 수량직접 확인한 실물 수량예정 수량과 분리
상태파손·포장 이상·확인 대기정상 물품과 구분 보관
보관 위치상자 번호와 보관 구역담당자가 같은 위치 확인
반출 권한물품을 꺼낼 담당자불출 기록 후 전달

표지의 팀 자리 사진에는 간식 상자와 생수, 물티슈가 보입니다. 경품 사진이나 실제 재고 관리 사례가 아니라 준비물을 구역별로 놓는 모습을 참고하는 사진입니다.

2. 무대에 올라갈 물품과 보관분을 나눕니다

한꺼번에 전량을 무대 옆에 두면 다음 순서 물품과 예비분이 섞일 수 있습니다. 진행표와 연결된 순서별 묶음을 만들고 보관 장소에서 꺼낸 내역을 기록합니다.

무대로 옮긴 수량을 곧바로 수령 완료로 적지 않습니다. 운영 담당이 받은 상태와 당첨자가 받은 상태는 서로 다른 단계입니다.

내빈석 사진은 의자 이름표와 공간 배치의 참고 장면입니다. 경품을 객석이나 통로에 쌓아도 된다는 뜻은 아니며 보관 위치는 장소 관리자와 확인합니다.

  • 진행용 목록에는 품목 코드와 소개할 품목명만 남깁니다.
  • 보관용 목록에는 위치, 실제 수량, 꺼낸 사람을 적습니다.
  • 무대 전달 담당은 받을 물품 코드를 읽고 실물 표시를 맞춥니다.
  • 통행이나 장비 조작을 방해하지 않는 보관 구역을 정합니다.

3. 추첨 번호와 실물 인계를 연결하는 표

당첨자를 확인하는 기준과 경품을 건네는 기준을 행사 전에 정합니다. 추첨 번호로 확인할지 다른 식별 방식으로 확인할지는 주최 측이 참가 방식에 맞춰 결정합니다.

단계남길 기록완료 기준
입고품목 코드·확인 수량·확인자실물이 지정 위치에 있음
운영팀 불출코드·꺼낸 수량·받은 담당두 담당이 내용 확인
당첨 확정추첨 식별값·대상 품목진행 결과 확인
전달 대기보관 위치·미전달 사유미수령 표시 유지
수령 완료확인 방식·전달 담당·전달 상태실물 전달 확인
잔여 인계미수령분·예비분·이상 물품인수 담당 확인

이 표의 식별값에는 진행에 필요한 정보만 씁니다. 경품 전달을 위해 모든 참가자의 상세 신상정보를 새로 모으거나 객석용 화면에 연락처를 띄우지 않습니다.

동명이인이나 대리 수상 호명은 시상식 명단 정리에서 별도로 확인할 수 있습니다. 이 글의 핵심은 이름 표기가 아니라 실물 이동과 잔여 수량입니다.

4. 미수령과 교환 요청은 보류 상태로 남깁니다

당첨자가 자리에 없거나 바로 가져가기 어려운 물품이면 주최 측이 정한 방법으로 안내합니다. 나중에 받겠다는 말만 듣고 전달 완료로 바꾸지 않습니다.

미수령분은 새 추첨용 물품과 섞지 않습니다. 재추첨이나 다른 사람에게 양도할 수 있는지는 사전에 정한 참여 조건과 주최 측 판단을 확인해야 합니다.

대리 수령 요청이 들어오면 현장 직원이 임의로 승인하지 않고 주최 측 확인 담당에게 연결합니다. 수령 권한을 확인한 방식과 처리 결과는 운영 기록에 남기되 필요 없는 증빙은 수집하지 않습니다.

포장 이상이나 물품 교환 요청도 별도 상태로 적습니다. 새 물품을 건넸다면 기존 물품의 회수 여부까지 기록해야 목록과 실물이 다시 맞습니다.

세금이나 금전 지급과 관련한 처리가 필요하면 주최 측 회계 담당에게 확인합니다. 이 글의 인계표가 회계 증빙이나 별도 의무 확인을 대신하지는 않습니다.

5. 종료 인계는 숫자보다 분류를 먼저 맞춥니다

남은 상자를 한곳에 모아 총수량만 세면 누구에게 전달할 물품인지 알 수 없습니다. 미수령 보관분, 미사용 예비분, 파손 또는 확인 대기분을 나눈 뒤 각 목록과 실물을 맞춥니다.

인수자가 물품과 기록을 함께 확인한 뒤 보관 책임을 넘깁니다. 담당자 이름만 적고 실제 물품은 다른 장소에 남겨 두지 않도록 이동 위치를 확인합니다.

  1. 행사 진행을 마친 목록에서 아직 전달되지 않은 항목을 추립니다.
  2. 보관 장소의 실물을 코드별로 대조하고 차이가 있으면 원인을 확인합니다.
  3. 차이가 해결되지 않은 항목은 추측으로 수량을 맞추지 않고 확인 중으로 표시합니다.
  4. 남은 물품의 인수 담당, 보관 장소, 참가자 문의 창구를 기록합니다.

종료 뒤 연락을 맡을 사람이 현장 운영 담당과 다르면 안내 내용도 넘겨야 합니다. 참가자에게 이미 알린 수령 방법과 아직 결정하지 않은 사항을 구분합니다.

6. 주최 측 준비와 진행 요청 범위를 구분합니다

힐링엔터테인먼트 하는 일에는 송년회 · 신년회 등 사내 행사와 전문 MC 진행이 포함되어 있습니다. 경품 실물의 구매, 보관, 배송까지 자동으로 맡는다는 의미는 아니므로 담당 구분을 먼저 정합니다.

무대 진행 · 현장 운영 가운데 추첨 안내와 물품 전달 연결을 어디까지 요청할지 견적 문의에 적습니다. 필요한 진행 항목은 자동 견적서에서도 확인할 수 있습니다.

상담에는 확정된 품목 목록, 추첨 방식, 현장 수령 여부와 보관 담당을 정리해 보냅니다. 아직 입고되지 않은 물품과 확인되지 않은 수령 조건은 별도 질문으로 남깁니다.

운영표를 공유할 때는 주최 측 승인본을 기준으로 합니다. 행사 뒤에는 필요한 인계 기록만 담당자가 관리하고 여러 곳에 흩어진 임시 전달본의 정리 시점도 정합니다.

미수령 보관분이 섞여 있을 수 있습니다. 미사용 예비분과 나누고 재추첨 여부는 사전에 안내한 조건과 주최 측 판단을 확인합니다.

경품 배송도 진행 요청에 포함되나요?

포함된 것으로 가정하지 않습니다. 구매·보관·현장 전달·추후 수령의 담당을 각각 정하고 요청할 운영 범위만 별도로 협의합니다.
