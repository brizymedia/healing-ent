행사 접수 명단 수정: 미등재·중복·현장 변경 처리표

읽는 시간 약 6분

행사 접수 명단 수정은 신청 상태와 도착 상태를 나눠 기록하는 것부터 시작합니다. 명단에 없다고 바로 돌려보내거나, 왔다는 이유만으로 신청 정보를 덮어쓰지 않습니다.

확인이 필요한 사람을 어떤 담당에게 연결할지 미리 정합니다.

  • 신청 확인과 도착 확인을 서로 다른 항목으로 둡니다.

1. 행사 접수 명단 수정 전에 기준 명단을 정합니다

사전 신청 파일과 주최 측 초청 명단이 따로 있으면 접수대마다 다른 자료를 볼 수 있습니다. 어떤 자료를 기준으로 확인할지 주최 측이 정하고, 자료가 합쳐지지 않은 부분은 확인 대상으로 표시합니다.

접수대에서 쓰는 자료에는 갱신 상태를 알 수 있는 표시를 둡니다. 파일 이름만 같고 내용이 다른 사본을 동시에 사용하지 않도록 현장 공유 방법을 정합니다.

명단 항목구분할 상태확인 목적
신청 상태신청 확인·확인 필요·취소참가 가능 여부 확인
도착 상태미도착·접수 확인·재확인현장 도착 기록
수정 상태요청 접수·승인 대기·반영 완료임의 변경 방지
확인 경로주최 측 지정 담당판단이 필요한 건 연결

사진은 팀 표지와 물품을 모아 둔 공간입니다. 실제 접수 명단이나 참가자 개인정보가 담긴 장면으로 소개하지 않고 자료와 물품 구분을 생각하는 참고 사진으로 사용합니다.

2. 명단에 없는 사람은 확인 대기로 연결합니다

이름이 검색되지 않으면 다른 표기나 신청 경로가 있는지 먼저 확인합니다. 단순 오탈자인지, 다른 행사 신청인지, 신청 자체가 확인되지 않는지 상황을 나눕니다.

접수 직원이 참가 자격을 임의로 결정하지 않습니다. 주최 측이 정한 확인 담당에게 연결하고, 답을 기다리는 참가자가 일반 접수 흐름을 막지 않도록 안내 가능한 위치를 확인합니다.

현장 등록이 가능한 행사인지도 미리 정해야 합니다. 빈 의자나 남은 물품이 있다는 이유로 현장 접수가 가능하다고 안내하거나 결제 조건을 임의로 만들지 않습니다.

  • 이름 표기와 신청 경로를 참가자에게 확인합니다.
  • 접수 불가라고 단정하기 전에 지정 담당에게 문의합니다.
  • 승인 대기와 접수 완료를 다른 표시로 남깁니다.
  • 결과가 나오면 참가자에게 전달한 상태까지 확인합니다.

3. 중복 신청과 동명이인을 구분합니다

같은 이름이 여러 줄 있어도 한 사람의 중복 신청이라고 단정하지 않습니다. 신청 경로나 내부 확인값으로 구분하되 주변 참가자가 들을 수 있는 자리에서 개인정보를 크게 읽지 않습니다.

같은 사람이 여러 번 신청한 것으로 확인되면 어떤 항목을 기준으로 남길지 주최 측이 정합니다. 현장 직원이 한 줄을 지웠다가 좌석이나 참가 구분 정보까지 사라지지 않도록 변경 전 내용을 확인합니다.

발견 상황먼저 할 확인기록할 처리
동일 이름 여러 줄서로 다른 신청자인지확인에 사용한 내부 구분
동일인 중복 신청남길 신청 정보가 무엇인지중복 확인과 반영 상태
이미 접수 표시재입장인지 잘못 누른 것인지추가 도착 여부 재확인
표기 수정 요청기준 정보와 수정 범위요청 내용과 승인 담당

본부석 천막 사진은 현장 안내 위치를 생각하기 위한 자료입니다. 이곳에서 실제 접수 업무를 수행했다거나 특정 방식의 명단을 사용했다고 주장하지 않습니다.

4. 현장 변경은 영향받는 자료까지 확인합니다

이름을 고치는 일과 참가 구분을 바꾸는 일은 영향 범위가 다릅니다. 좌석이나 지급 물품, 팀 편성이 연결돼 있다면 관련 담당에게 변경 내용을 확인시킵니다.

명단 수정은 요청과 반영 완료를 구분합니다. 참가자가 요청했다고 바로 다른 자료까지 변경된 것으로 보지 않고, 승인 담당과 반영 담당을 기록합니다.

접수 화면이 참가자 쪽으로 보일 때는 다른 사람의 연락처나 메모가 노출되지 않도록 화면 방향과 표시 범위를 살핍니다. 공개 확인용 화면에는 해당 참가자 안내에 필요한 정보만 표시합니다.

  • 기존 값과 요청한 값을 혼동하지 않게 적습니다.
  • 관련 좌석·팀·물품 자료의 담당에게 알립니다.
  • 처리되지 않은 건은 남은 확인 담당을 표시합니다.
  • 완료된 변경을 참가자에게 다시 안내합니다.

5. 연결이 끊긴 경우를 위한 확인 방법을 준비합니다

공유 명단을 사용할 수 없으면 직원마다 새 명단을 만들어 접수 완료를 따로 표시할 수 있습니다. 이런 상황에서 중복 확인이 생기지 않도록 주최 측이 사용할 임시 기록 방식을 정합니다.

빈 체육관의 표지와 도구 사진은 준비 공간을 보여 줍니다. 사진 속 표지에 참가자 신청 정보가 담겼다고 추측하지 않습니다.

임시 기록에는 이후 합치기에 필요한 최소 항목과 확인 담당을 남깁니다. 연결이 복구되면 임시 기록과 기준 명단을 대조하고, 대조가 끝나기 전에 어느 한쪽을 임의로 폐기하지 않습니다.

접수가 끝난 뒤에는 도착 현황과 미처리 요청을 분리해 주최 측에 전달합니다. 최종 참석 수나 참가 결과를 확인 없이 대외 실적으로 발표하지 않습니다.

6. 현장 접수의 승인 범위는 주최 측과 맞춥니다

힐링엔터테인먼트가 안내하는 기업 체육대회 · 워크숍 · 팀빌딩, 무대 진행 · 현장 운영은 행사별 협의가 필요한 업무입니다. 전문 MC 진행을 요청했다고 신청 데이터 관리나 참가 자격 판단까지 포함되는 것은 아닙니다.

견적 문의에 사전 신청 방식과 접수대 운영 요청, 현장 변경의 승인 담당을 적습니다. 자동 견적서에서 필요한 진행 항목을 확인하되, 명단 관리의 업무와 정보 전달 범위는 별도로 협의합니다.

접수 종료 뒤 자료를 누가 보관하고 어떻게 정리할지도 주최 측이 정합니다. 여러 개인 기기에 남은 사본을 임의로 활용하거나 다른 행사 안내에 사용하지 않도록 목적과 처리 방법을 맞춥니다.

현장 등록 가능 여부와 승인 담당을 먼저 확인합니다. 명단 미등재를 발견하면 신청 경로를 확인하고 주최 측의 판단 결과를 반영합니다.

동명이인일 수 있으므로 바로 삭제하지 않습니다. 내부 확인 정보로 구분하고 중복이 확인된 경우에도 남길 정보와 반영 범위를 정합니다.

주최 측이 정한 임시 기록 기준을 사용합니다. 복구 후 기준 명단과 대조할 항목을 남기고 중복 접수 표시가 생기지 않도록 확인합니다.
