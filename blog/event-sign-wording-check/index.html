행사 안내판 문구 검수: 목적지·행동·예외를 나누는 법

읽는 시간 약 5분

행사 안내판 문구 검수는 예쁜 표현보다 참가자가 같은 목적지를 같은 이름으로 찾게 하는 일입니다. 어디로 가야 하는지, 도착해서 무엇을 해야 하는지, 이용할 수 없는 경우 어디에 물어야 하는지를 나누면 문구를 짧게 유지하면서도 필요한 정보를 담을 수 있습니다.

  • 목적지 이름은 배치도·안내판·방송에서 같은 말로 씁니다.

1. 행사 안내판 문구 검수는 목적지 목록부터 시작합니다

담당자에게 익숙한 방 이름이 처음 온 참가자에게도 통하는 것은 아닙니다. 실제 사용 가능한 창구와 구역을 배치도에 표시하고 공개할 이름을 먼저 정합니다.

한 목적지에는 하나의 공개 이름을 씁니다. 안내소, 운영본부, 접수처가 같은 장소를 가리킨다면 서로 다른 업무인지 단지 표현만 다른 것인지 주최 측이 정리합니다.

건물 이름과 행사 임시 구역명을 함께 쓸 때는 관계를 알 수 있게 적습니다. 내부 담당만 아는 약칭이나 준비 과정에서 바뀐 이름을 그대로 출력하지 않습니다.

2. 길을 찾는 말과 일을 설명하는 말을 분리합니다

이동 중 읽는 표지에는 목적지와 방향을 중심으로 적습니다. 도착한 뒤 읽는 표지에는 처리하는 업무와 이용 조건을 두어 한 장에 모든 설명을 넣지 않습니다.

아래 표는 문안을 나누는 예시입니다. 실제 방향과 이용 가능 여부는 현장 확인 뒤 채우고, 확인 전 초안의 화살표를 확정본처럼 사용하지 않습니다.

방향을 말하는 문구는 표지를 설치할 위치에서 읽어 봅니다. 문서에서 오른쪽이던 방향이 표지를 반대편에 세우면서 달라지는지 확인해야 합니다.

3. 문구를 읽고 실제 행동을 말해 보게 합니다

초안을 만든 사람 대신 내용을 처음 보는 담당에게 표지를 읽고 어디로 갈지 말해 달라고 요청합니다. 설명을 덧붙이지 않아도 목적지를 찾을 수 있는지 확인하는 검토입니다.

읽은 뒤 행동이 갈리면 문구를 다시 씁니다. 문장이 친절해 보이는지보다 접수하는 곳과 기다리는 곳을 구별할 수 있는지를 봅니다.

복도 끝, 무대 옆 같은 표현은 바라보는 방향에 따라 달라질 수 있습니다. 현장에서 식별 가능한 구역 이름을 먼저 쓰고, 필요하면 배치도와 같은 표시를 함께 사용합니다.

부정 문구만 있는 표지는 다음 행동을 남기지 못할 수 있습니다. 출입할 수 없다는 안내 뒤에 확인된 문의 위치나 대안 경로를 덧붙이되 임의로 새 길을 만들지 않습니다.

4. 예외 조건은 확인된 범위만 적습니다

접수를 마친 사람과 현장 확인이 필요한 사람의 절차가 다르다면 대상과 다음 행동을 구분합니다. 모두 이쪽으로 오라는 문장으로 서로 다른 업무를 한 줄에 모으지 않습니다.

개별 참가자의 이름이나 사정을 표지에 적어 구분하지 않습니다. 공개 표지는 업무 유형을 안내하고 세부 확인은 해당 창구에서 하도록 주최 측 절차를 맞춥니다.

이용 가능하다는 표현은 장소와 운영 확인 뒤에 씁니다. 편의시설이나 별도 서비스가 제공된다고 추정하지 않고 확인할 창구를 표시합니다.

사진은 입구, 팀 자리, 본부석 장면을 보여 주는 참고 자료입니다. 사진 속 표지의 실제 문구나 안내 효과를 검증한 사례로 설명하지 않습니다.

5. 수정본은 출력물과 말 안내까지 연결합니다

문안을 고쳤으면 표지 번호와 설치 위치를 묶어 교체 목록을 만듭니다. 파일을 새로 저장한 것과 현장의 예전 종이를 걷어 낸 것은 별도 확인입니다.

여러 장을 한꺼번에 바꾸지 못한다면 어떤 구간에 이전 내용이 남아 있는지 담당에게 알립니다. 잘못된 표지를 방치한 채 방송만으로 정정했다고 끝내지 않습니다.

교체 완료는 설치 위치에서 확인합니다. 사용하지 않는 문과 닫힌 창구에 과거 안내가 남지 않았는지 참가자가 이동하는 순서로 살펴봅니다.

안내 담당에게는 문안 전체보다 달라진 목적지와 적용 대상을 먼저 전달합니다. 아직 확인 중인 경로를 확정 경로처럼 말하지 않도록 보류 항목도 구분합니다.
